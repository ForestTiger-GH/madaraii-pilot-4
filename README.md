# Календарная работа

Основное пространство для отдельных крупных аналитических задач.

Каждая новая самостоятельная задача создаётся в собственной папке формата:

`ГГГГ-ММ-ДД-Наименование задачи на русском`

Дата соответствует началу задачи и обеспечивает хронологическую сортировку рабочих контуров.

Папка задачи является её основным рабочим пространством. Внутри неё ведётся относящаяся к задаче работа и хранятся её собственные материалы: постановка, исходные данные, исследования, расчёты, промежуточные результаты, итоговые материалы и иные необходимые артефакты.

Общие материалы рабочего пространства в папку задачи не копируются без необходимости. При потребности задача обращается к ним по их основному месту хранения.

Внутренняя структура папки задачи определяется самой задачей и создаётся по мере фактической потребности.
