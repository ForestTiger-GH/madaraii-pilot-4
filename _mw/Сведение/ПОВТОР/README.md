# ПОВТОР — сведение

## Назначение

Вторая итерация сведения по банкам на основе Research Results из `Исследования/ПОВТОР/`, построенных по вручную предоставленным первичным файлам отчетности.

Один банк и один reporting lens = одна самостоятельная Work сведения.

## Метод

- Инженерный маршрут: `MADARAII-10 — Research Corpus Synthesis`.
- Аналитическая основа: актуальный `Мандат аналитической работы_v2.md`.
- Source universe замораживается на актуальном HEAD и включает все завершенные повторные Research Results данного банка только по выбранному reporting lens.
- МСФО и РСБУ не смешиваются.
- Новый внешний Research в ходе сведения не выполняется.
- Первую итерацию `Сведение/Банки/` можно читать только после самостоятельного построения нового сведения как challenge/check layer; старые выводы и цифры автоматически не переносятся.
- Все материальные расхождения между периодами, perimeter, методикой, классификациями и расчетами сохраняются явно.
- `REPORTED`, `DERIVED`, `INTERPRETED` и `UNKNOWN` сохраняются раздельно.

## Выход

Файлы результатов лежат непосредственно в двух папках без дополнительных каталогов:

- `МСФО/<Банк>-2026-2К.md`;
- `РСБУ/<Банк>-2026-2К.md`.

Одна Work создает только один такой файл и после завершения останавливается.
