# ПОВТОР — РСБУ

## Назначение

Вторая итерация исследований РСБУ и регуляторной отчетности на основе первичных файлов, вручную предоставленных пользователем.

Исходный контур `../../РСБУ/` сохраняется как история первой итерации и в рамках повторного анализа не изменяется.

## Маршрут работы

- Перед каждой Work прочитать корневой и локальный `AGENTS.md`, актуальный `Мандат аналитической работы_v2.md`, а также актуальные `FOUNDATION`, `MADARAII-08` и `EXAMPLE-08` из ветки `dev` репозитория `MADARAII`.
- Один банк и полный доступный комплект РСБУ/регуляторных форм за 3М2026 и 6М2026 = одна самостоятельная `MADARAII-08 — Substantive Research`.
- Основной источник — предоставленные первичные формы и файлы отчетности. Официальные формы Банка России используются как равноправный первичный слой. Вторичные агрегаторы применяются только для сверки и поиска расхождений.
- Разделять балансовые точки, накопленные потоки и расчетный чистый II квартал. `6М − 3М` использовать только при совпадающих perimeter, методике и классификации.
- Не смешивать РСБУ с МСФО. Сохранять различия между публикуемой бухгалтерской отчетностью, регуляторными формами, внутренними банковскими KPI и расчетными показателями.
- Старые Results из `../../РСБУ/` читать после самостоятельного анализа первичных файлов как challenge/check layer. Расхождения сохранять явно; старые цифры не переносить автоматически.

## Выход

Рекомендуемый маршрут результата:

`ПОВТОР/РСБУ/<Банк>/2026-2К/RESULT.md`

Повторная Work не выполняет МСФО-анализ, межбанковское сведение, общий синтез или Jester.
