# Исследования

Здесь хранятся самостоятельные результаты исследований по задаче.

Основные направления:

- `МСФО/` — первая итерация исследований отдельных отчетов МСФО;
- `РСБУ/` — первая итерация совокупных исследований РСБУ и регуляторной отчетности по банкам;
- `Новости/` — событийный контур по банкам;
- `Тематические исследования/` — исследования отдельных тем по всему банковскому universe;
- `Общее/` — общие исследования макроэкономики и банковского сектора;
- `ПОВТОР/` — вторая итерация МСФО и РСБУ на основе вручную предоставленных первичных файлов отчетности.

Каждый результат должен сохранять предмет, период, использованные источники, наблюдения, расчеты, выводы и ограничения. Исследовательские материалы остаются доступной доказательной историей после последующих сведений и синтеза.
