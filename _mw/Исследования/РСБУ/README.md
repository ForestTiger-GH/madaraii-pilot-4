# Исследования РСБУ

По каждому доступному банку проводится одна отдельная Work, охватывающая совокупность доступной отчетности РСБУ за II квартал 2026 года и необходимые граничные даты.

РСБУ используется как дополнительный наблюдательный слой к МСФО. Расхождения в периметре, методике и периодизации должны сохраняться явно и учитываться при последующем сведении.
