# Паспорт задачи

Задача — анализ финансовой отчетности МСФО крупных банков за II квартал 2026 года. Продукт — знание.

Текущая папка является рабочим контуром внутри единого MADAR workspace репозитория `analytics`. Отдельный workspace внутри нее не создается. Вся работа по задаче ведется только в этой папке.

## Управляющая основа

- `../../AGENTS.md` — паспорт репозитория.
- `INBOX.md` — исходное поручение.
- `../../Мандаты/Мандат аналитической работы_v2.md` — обязателен для аналитики.
- `../../Мандаты/Мандат деловой коммуникации_v3.md` — обязателен для финального файла тезисов.
- Инженерный процесс ведется по актуальным MADARAII из ветки `dev` репозитория MADARAII.

## Организация

- отдельный отчет МСФО по банку — отдельная исследовательская работа в `Исследования/МСФО/`;
- в каждом отдельном исследовании МСФО желательно фиксировать широкий набор важных показателей банка как самостоятельную доказательную базу; форма может быть табличной или текстовой, состав определяется материалом отчета и значимостью показателей;
- затем формируется сведение по каждому банку за период в `Сведение/`;
- РСБУ по каждому банку анализируется отдельной совокупной работой в `Исследования/РСБУ/`;
- сектор, экономика и новости исследуются отдельными контурами;
- результаты сводятся и синтезируются в единый корпус знания `WHAT + Science`;
- `WHAT` здесь означает непосредственный аналитический результат, а `Science` — его доказательную и объяснительную основу;
- после консолидации выполняются минимум два последовательных Jester-прогона с последующей обработкой результатов каждого прогона.

Текущее состояние и следующий безопасный шаг фиксируются в `Работа/СОСТОЯНИЕ.md`.

## Конечные артефакты

В корне задачи по завершении должны находиться:

- `ПРОДУКТ.md` — единый корпус `WHAT + Science`;
- `ТЕЗИСЫ.md` — тезисный аналитический материал в деловой форме;
- `ОТЧЕТ-О-РАЗРАБОТКЕ.md` — отчет о выполненной работе.

Пустые заглушки финальных файлов не создаются. Архивирование и удаление материалов не предполагаются.
