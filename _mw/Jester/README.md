# Jester

После первичной консолидации корпуса знания выполняются минимум два последовательных Jester-прогона по актуальной MADARAII-40.

Каждый прогон получает отдельный Jester Report и собственный Baseline. После каждого прогона его содержательные сигналы должны быть отдельно обработаны и reconciled до следующей консолидации.

Минимальная последовательность:

1. первичная консолидация знания;
2. Jester 1;
3. обработка результатов и доработка;
4. новая консолидация;
5. Jester 2;
6. обработка результатов и финальная доработка.

Второй прогон по возможности формируется независимо от провокационного framing первого. Дополнительные прогоны допустимы, если сохраняется материальная ценность.
